# Generative 8-Reference Visual Canvas Guide (ProdigeUI)

> **Grade Target**: Awwwards Site of the Day / FWA (9.5+/10)  
> ⚠️ **Strict Anti-Slop Rule**: Do NOT copy hardcoded HTML code blocks or fixed theme hex values. Synthesize design reads dynamically across reference signatures.

---

## 1. Intent & Brand Stance

Synthesize visual signatures derived from 8 world-class reference sites (yoyoyo.ai, n8n, framer, stripe, delve architects, nestjs, antimetal, plasma):

1. **yoyoyo.ai Signature**: Fluid typography clamp scales, high-altitude whitespace, un-crammed editorial cards.
2. **n8n Signature**: Visual node DAG canvas with ports, execution pulse state, dark obsidian theme.
3. **Stripe Signature**: Material inset depth (`box-shadow: inset 0 1px 0 0 rgba(255,255,255,0.12)`), glassmorphic nav.
4. **Delve Signature**: Tactile paper palette (`#f5f2eb`), Instrument Serif display type, brutalist grid lines.

---

## 2. Non-Negotiable Guardrails

- **Zero Inline HTML Styles**: All styling declared via semantic CSS variables.
- **Strict Container Boundary Containment**: Parent cards declare `overflow: hidden;` so child images never bleed past rounded corners.
- **Tab Switch Layout Stability**: Grid cells lock height (`height: 100%; min-height: 420px;`) with 0px layout shift.
- **WCAG AA Compliance**: 4.5:1 minimum contrast on body copy, 7.0:1+ on display text.
