# Generative Operational SaaS Hero Guide (ProdigeUI)

> **Target Use-Case**: B2B Engineering SaaS, DevOps, Infrastructure, Security, and Operational AI tools (e.g. FlowAI).  
> ⚠️ **Strict Anti-Slop Rule**: Do NOT copy hardcoded HTML boilerplate or fixed CSS hex values. Synthesize layout geometries, HSL color tokens, and domain copywriting dynamically.

---

## 1. Intent & Brand Stance

- **Brand Emotion**: Technical authority, real-time precision, sprint accountability, engineering clarity.
- **Palette Synthesis**: Dark Obsidian (`#0b0d10`) or Deep Navy (`#0a0f1d`) surface + Electric Lime (`hsl(82, 100%, 61%)`) or Signal Vermilion accent. Minimum 7.5:1 text contrast.
- **Typography Pairing**: `Space Grotesk` or `Syne` (Display) + `Inter` (Body) + `JetBrains Mono` (Telemetry & Code).

---

## 2. Generative Grid & Layout Architecture

- **Asymmetric 2-Column Hero**: Grid ratio `1.1fr 0.9fr` or `1fr 1fr` with `align-items: stretch;`.
- **Left Editorial Column**: Sub-tag eyebrow in mono + fluid display title + concise 2-line lead description + high-contrast CTA button.
- **Right Interactive Engine Anchor**:
  - **Live JS PR Telemetry Inspector**: Interactive pull request risk selector (`selectPR(id)`).
  - **Height-Locked Grid Cell**: Viewport fills grid cell height via `height: 100%; min-height: 420px;` (no aspect-ratio overflow conflicts).
  - **Container Boundary Containment**: Parent card declares `overflow: hidden;` and `border-radius: 16px;`.

---

## 3. High-Craft Copywriting Rules

- **Zero Prompt Leaks**: Prohibit debug text or click hints like `(CLICK TO SWITCH...)`.
- **Authentic Engineering Metrics**: Use precise metrics (`PR #1084 API Schema Shift`, `2 Microservices Affected`, `12% Risk Score`).
