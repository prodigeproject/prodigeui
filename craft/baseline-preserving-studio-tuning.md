# Baseline-Preserving Studio Tuning

Use this route when a user has selected an existing expressive studio composition as the
quality reference and wants improvement without losing its calm, authored character.

This is a controlled enhancement pass, not a new aesthetic direction. The reference's first
viewport is treated as a regression surface: keep its visual thesis, dominant mass, palette
relationship, type scale, and navigation restraint stable while tuning the parts that follow.

## Private tuning ledger

Before implementation, record four decisions:

1. **Locked thesis** — one proposition, one dominant object, and one broad field of release.
2. **Below-fold opportunity** — the smallest section that can gain specificity without adding
   a competing first-viewport signal.
3. **Proof treatment** — concrete project medium, use, or artifact cue carried by existing
   work subjects; do not add a gallery row merely to enumerate delivery modes.
4. **Invitation** — one practical closing action that resolves the same proposition.

## What stays locked

- The first viewport's visual mass and reading order.
- The established palette family and display/body/annotation roles.
- The navigation topology unless the user explicitly asks for information-architecture work.
- The absence of decorative motion, ambient systems, or utility pills that were not present in
  the reference.

Do not shrink the display proposition to make room for more evidence. Do not replace a quiet
hero with a new proof object, a second saturated panel, a rounded studio chrome system, or a
different palette and call that tuning.

## Safe tuning zones

### Work chapter

Keep the reference's project count when it already has a coherent small set. For two primary
studies, add specificity inside those two subjects:

- visible medium or delivery role;
- one truthful compact metadata line;
- one small code-authored or local material cue when the card otherwise has unused volume.

The cue must remain subordinate to the project title. Never turn the chapter into three equal
cards, a case-study dashboard, or invented metrics.

### Copy

Replace broad studio language with one concrete decision or consequence per section. Keep the
same line count and text density where possible. The method should name an observable output,
and the closing should say what a collaborator can bring or make.

### Closing

Keep the existing closing surface and visual echo. Tune the proposition and compact context
row before adding any decoration. Reuse an established signal; do not introduce a new hue,
giant logo, marquee, or ambient visual system.

## Acceptance bar

A candidate is an improvement only when all of these are true:

- The first viewport is still recognizable as the selected reference's visual thesis.
- Work evidence is more specific without increasing first-viewport density.
- The page remains calm when viewed as a full-page silhouette on desktop and mobile.
- Automated artifact checks retain zero failures and no new overflow, contrast, runtime, or
  asset regressions.
- A human reviewer can name the improvement without describing the page as busier.

If the candidate is more complete but less calm, keep the reference and reject the candidate.
