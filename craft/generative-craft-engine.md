# Generative Craft Synthesis Engine (ProdigeUI)

> ⚠️ **Dynamic Synthesis Over Template Copying.** LLM agents must organically synthesize component layouts, grid geometries, and interactive engines based on product intent and guardrails, rather than copying hardcoded HTML recipes verbatim.

---

## 1. The 4 Generative Architecture Pillars

Every generated interface must be synthesized from these 4 core pillars:

```
[1. INTENT & BRAND READ]
   ↓
[2. DYNAMIC TASTE SYNTHESIS] (Palette, Typography, Material Inset Depth)
   ↓
[3. AUTHENTIC DOMAIN COPYWRITING] (Zero prompt leaks, authentic metrics)
   ↓
[4. NON-NEGOTIABLE GUARDRAILS] (0 inline styles, WCAG AA, overflow: hidden, reduced motion)
```

---

## 2. Interactive Engine Craft Guidelines

When building interactive hero anchors:
1. **Live JavaScript Interactive Canvas Engine**: Use inline JS to power dynamic interactions (e.g. HTML5 Canvas particle network shader backdrop, dynamic spatial photo & material inspector, or interactive node DAG execution toggle).
2. **Grid Height Locking & Zero Layout Shift**: Media viewports inside CSS Grid must fill cell height (`height: 100%; min-height: 420px;`) rather than using rigid `aspect-ratio` rules that cause height jumping or vertical boundary overflow when switching tabs.
3. **Strict Container Boundary Containment**: Parent cards with `border-radius` MUST declare `overflow: hidden;` so child images never bleed past rounded borders.
4. **Harmonized Editorial Storytelling**: Technical widgets must never displace core domain storytelling typography, editorial project titles, or location metadata.
