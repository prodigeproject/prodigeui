# Benchmark Brief (VAGUE — Creative Mode)

Build a single-page landing for "FlowAI" — an AI project management tool for engineering teams.

Sections needed:
- Hero with headline and CTA
- 3 key features
- Social proof / metrics
- One testimonial
- Pricing (3 tiers)
- FAQ (4 questions)
- Final CTA
- Footer

Target audience: startup CTOs and engineering managers.

That's it. No colors specified. No layout specified. No images specified. No fonts specified.
The AI must make ALL design decisions.

This tests whether ProdigeUI produces visually BETTER output than raw AI default behavior.
