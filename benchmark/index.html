Gap ledger

Every gap became a concrete ProdigeUI edit.

The benchmark's value isn't the ranking — it's that each deficit maps to a shipped change in the system's rules and craft docs.

G1High

Motion used Material-style easing

No interaction-motion craft. Added craft/patterns/motion-craft.md with a frequency gate, committed curves, never-scale(0) and interruptibility.

G2High

No modern interaction/a11y patterns

Added interaction-patterns.md: native <dialog>/inert, Popover API + anchor positioning, roving tabindex, forms, undo-over-confirm.

G3High

Missing mechanical layout hard-rules

Expanded craft/taste.md + quality gate: CTA wrap, no duplicate CTA intent, nav single-line, zigzag ≤2, bento cell-count, icon discipline.

G4Med

Anti-slop lacked exact banned hex

Added the exact indigo hex list, an accent-overuse cap, the 80/20 soul rule and an outsider-screenshot test to the checklist.

G5Med

No brief→real-design-system routing

Added design-system-routing.md mapping briefs to official packages (Fluent/Carbon/Material/Radix/shadcn) instead of always inventing tokens.

G6Med

No strict animation-review lens

Added skills/motion-review: 10 non-negotiables, escalation triggers, a findings table and a Block/Approve verdict.

G7–G10 (effect-naming vocabulary, breadth baselines, command taxonomy, aesthetic preset catalog) are tracked — some shipped, some deliberately deferred as content projects. Full record in improvements-changelog.md.

The net effect

Four dimensions moved. Average 3.9 → 4.6.

Integrating impeccable's interaction depth, emil's motion craft, taste-skill's mechanical rules and open-design's linted bans into one system moved ProdigeUI ahead of the strongest single comparator.
