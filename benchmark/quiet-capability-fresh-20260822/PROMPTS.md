# Fixed evaluation briefs

## MIRA / fashion commerce

Create a product-detail experience for a small Jakarta capsule-fashion label.
A person is choosing a travelling linen set. The first view must establish the
garment and the one decision they can make now: chosen trouser size. Price and
the immediate add-to-bag action must be clear. Delivery, exchange, and the
selected-size confirmation must remain available, but should not compete with
the garment before the person acts. Use the supplied model photo as fit and
silhouette evidence.

## Relay / operational release SaaS

Create a release-readiness workspace for a product lead considering an iOS
rollout. The person must see the single unresolved blocker and start a release
check. Ownership assignment and the result/recovery path must be runnable, but
they should appear when the blocker or action requires them rather than as a
permanent dashboard of explanations. This is recurring operational work, not a
marketing page.

## Rasa / care navigation

Create a non-emergency care entry experience for a person with a new concern.
Urgent escalation must be immediately visible. The person needs a safe first
route without knowing clinical specialty names, then a reachable appointment
option. Keep safety, language clarity, and recovery ahead of decorative calm.
Use the supplied consultation photo as relevant care context.

## ORION / automotive booking

Create a low-pressure test-drive planner for an electric vehicle. A potential
buyer needs to recognize the vehicle, choose a day, request an available time,
and see what happens after a time is selected or unavailable. The initial view
should hold attention on vehicle evidence and one reversible planning action,
not a permanent confirmation dashboard. Use the supplied vehicle photo.
