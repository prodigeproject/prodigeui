## Prompt to Recreate HavenCraft — Minimalist Home Decor Landing Page

**Build a single-page "HavenCraft" minimalist home decor e-commerce landing page using React, Tailwind CSS, and Lucide React icons. The page features a split-screen hero with parallax-scrolling product imagery, a horizontal-scroll product carousel, room inspiration gallery, and a smooth newsletter signup. Use Vite + TypeScript.**

---

- **Cormorant Garamond** (weights: 300, 400, 500, 600) — hero heading, section titles, quotes
- **Outfit** (weights: 300, 400, 500, 600) — body/UI text, navigation, buttons

```
https://fonts.googleapis.com/css2?family=Cormorant+Garamond:wght@300;400;500;600&family=Outfit:wght@300;400;500;600&display=swap
```

### Animations

| Class | Effect | Duration | Easing |
|-------|--------|----------|--------|
| `.animate-fadeIn` | opacity 0→1 | 0.8s | ease-out |
| `.animate-slideUp` | translateY(28px)→0 + opacity 0→1 | 0.9s | cubic-bezier(0.16, 1, 0.3, 1) |
| `.animate-slideInLeft` | translateX(-20px)→0 + opacity 0→1 | 0.8s | cubic-bezier(0.16, 1, 0.3, 1) |
| `.animate-scaleReveal` | scale(1.05)→1 + opacity 0→1 | 1.1s | cubic-bezier(0.22, 1, 0.36, 1) |

All with `animation-fill-mode: both`. Delay utilities: `.delay-200` through `.delay-1200` in 200ms steps.

**Scroll reveal:** IntersectionObserver at threshold 0.12, elements with `.rv` start opacity-0 translate-y-6 and transition to visible when intersecting. Stagger: each child delayed by index * 80ms.

**Parallax (hero image):** On scroll, apply `transform: translateY(${scrollY * 0.3}px)` to hero image element. Use `requestAnimationFrame` for smooth updates. Disable under `prefers-reduced-motion`.

### Responsive Breakpoints
- Mobile (default): single column, stacked layout, hero image below content
- md (768px): 2-col grids, larger type, side padding increases
- lg (1024px): split hero, 3-col bento, horizontal carousel visible, full nav
- xl (1280px): max-width container, generous whitespace

### Key Technical Details
- Color scheme: LIGHT mode (warm, earthy, Japandi-inspired)
- Buttons: rectangular (rounded-none or rounded-sm) for primary CTAs — this is a deliberate design choice matching the architectural/minimal aesthetic. Pills (rounded-full) used only for tags and form inputs.
- Smooth scroll: `html { scroll-behavior: smooth; }`
- All images: loading="lazy" except hero. Include `onerror` fallback to bg-surface.
- Nav scroll effect: useState + useEffect with scroll listener, debounced via requestAnimationFrame
- Horizontal carousel: useRef on scroll container, prev/next buttons call `scrollBy({ left: ±340, behavior: 'smooth' })`
- Lucide icons used: Search, Heart, ShoppingBag, ChevronLeft, ChevronRight, ArrowRight, Play, Menu, X, Instagram, Dribbble
- Marquee uses duplicated content div trick: two identical spans side-by-side, parent overflow-hidden, animate the wrapper translateX(-50%)
