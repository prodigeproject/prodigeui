# Market-Calibrated Fresh Generation — 22 August 2026

This benchmark is a fresh, manually authored set of ten independent product
experiences. It is not produced by a shared HTML generator, shared stylesheet,
or canned section order. Each page begins with a Product Opportunity Record,
Market Reference Read, selected experience archetype, dominant proof, and a
rejected generic fallback.

It tests whether the tuned ProdigeUI system can make a product's task, market,
and differentiator visibly change the page form—not merely recolor a shared
landing page.

## Cross-case expectation

The pages should visibly differ in topology, evidence type, density, action
placement, type behavior, and sequence because the underlying decision changes.
This is a qualitative design audit, not a claim of universal product quality or
user preference. The live references were read on 22 August 2026 and are used
for structural calibration only; no reference identity, copy, or visual geometry
is copied.

## Manual review criteria

- The first viewport exposes the selected archetype and the first user decision.
- The dominant media or UI state reduces an actual uncertainty.
- The primary action is near the evidence that makes it reasonable.
- Each case declares an honest route to feedback, result, and recovery.
- At least four of the seven identity-collapse dimensions differ from every
  unrelated neighboring case for a product reason.
- Desktop and compact layouts retain the primary task, evidence, and action.
