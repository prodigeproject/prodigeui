# Research-integrated fresh GPT benchmark

## Protocol

- Generator: GPT in the current Codex task, authoring HTML directly (not a generation script).
- Authority: current integrated ProdigeUI after research-critical rules were distributed into canonical generation, craft, motion/material, responsive, and quality-gate subsystems.
- Control: the latest fresh pair in `fresh-context-llm/prodigeui-full-context-{flowai,nova}.html`.
- Briefs: same FlowAI operational-product and NOVA expressive-studio briefs used by the previous fresh benchmark.
- No control or approved HTML was used as generation geometry.

## Comparison

### FlowAI

The new build is more product-specific in its first viewport: the focal artifact is a decision feed with evidence, confidence, ownership, consequence, and reversible recommendation states. Proof and security language are explicitly marked as illustrative or requiring confirmation instead of being presented as fabricated fact. The composition uses a calm light product palette and active negative space without treating grain, glass, or engine motion as required craft.

Compared with the latest fresh control, it is leaner in source size while retaining the required inventory. Its strongest improvement is semantic product credibility. The trade-off is less ambient spectacle; this is intentional for an operational product and should be judged on clarity and trust rather than effect count.

### NOVA

The new build organizes the page around one proposition—“brands with gravity”—and repeats that idea through scale, orbit-like geometry, project language, and the closing invitation. Project fields vary in scale and rhythm instead of collapsing into equal portfolio cards. It deliberately uses no JavaScript, grain overlay, glass, or generic WebGL; identity comes from composition, typography, color blocking, and concept-bound artwork.

Compared with the latest fresh control, it is materially leaner and less dependent on a scripted signature. The benefit is stronger conceptual coherence and a clearer distinction between signature and supporting techniques. The trade-off is that the campaign artwork is CSS-authored rather than real client media, so production replacement with licensed work imagery would increase credibility.

## Result

The integrated system changes the quality mechanism rather than reproducing a fixed look:

- FlowAI converges toward evidence, consequence, reversibility, and domain-specific UI.
- NOVA remains expressive but avoids using effects as proof of modernity.
- Both remain fresh compositions and retain offline safety, reduced-motion handling, focus visibility, clean encoding, and complete HTML.

Visual review is available in `index.html`. Automated in-app rendering could not be recorded because the browser security policy blocks local `file://` navigation; no browser workaround was used.
