This is a comparative **fresh-generation fixture**, not a claim that one
artifact proves universal model performance. Every one of the ten pages was
independently authored for this evaluation; there is no shared page generator or
shared CSS sheet. The five product briefs are held constant across a pair:

1. MIRA — editorial fashion commerce
2. Relay — operational release SaaS
3. Rasa — care navigation
4. ORION — high-consideration automotive booking
5. Kala — cultural visit planning

The pairs use the same local image where photo evidence is relevant. That holds
the visual subject constant so typography, colour roles, header topology, state
design, and action feedback can be inspected without attributing the result to a
different image.

## How to read it

- **Baseline is not a straw man.** It retains product-specific architecture,
  genuine evidence, and meaningful action labels from the accepted baseline.
- **Tuned is not allowed to win for being louder.** It must demonstrate a real
  font plan, task-specific header, semantic state roles, one runnable action
  chain, visible recovery, keyboard/focus support, and a reduced-motion path.
- **Interactions are intentionally inline, not generated by a benchmark script.**
  The tuned pages use small page-specific behavior to make the selected product
  action observable. Baseline pages remain static because the missing action
  state is one of the tested gaps.
- Inspect both desktop and compact widths. The comparison cannot be decided from
  hero screenshots alone.

## Controlled limitations

- This is one deliberate fresh artifact per side and product, not a multi-model
  statistical evaluation.
- Simulated pending/error/success states illustrate interface contracts; they do
  not call real inventory, booking, care, payment, or release APIs.
- System-font stacks are intentional and documented in each tuned page to avoid
  a false custom-font claim. Their exact appearance remains platform-dependent.
- The benchmark is a decision aid. See `SCORECARD.md` for the honest result,
  including regressions and remaining failures.
