# Fixed evaluation briefs

These prompts were held constant within each baseline/tuned pair. A page may
change topology only when its current system rule gives a product-specific reason
to do so.

## 1. MIRA / fashion commerce

Create a product-detail experience for a small Jakarta capsule-fashion label.
A person wants to choose a travelling linen set with enough fit, colour, size,
delivery, and exchange confidence to add it to their bag. Use the supplied model
photo as evidence. The first action must be adding a specific selected size to a
bag; show what happens if stock becomes unavailable.

## 2. Relay / operational SaaS

Create a release-readiness workspace for a product lead reviewing an iOS rollout.
They must find the remaining risks, see an owner, start a release check, and
recover when a blocker lacks ownership. This is frequent operational work, not a
SaaS marketing landing page.

## 3. Rasa / care navigation

Create a non-emergency care entry experience. A person has a new concern and
needs the safest appropriate starting route without knowing medical specialty
names. Preserve urgent escalation, explain what information is needed, and show
a reachable next appointment route without pretending to provide medical advice.

## 4. ORION / automotive booking

Create a test-drive planner for an electric vehicle. A potential buyer needs to
select model, location, and a time, understand what is retained, and receive a
confirmation or an honest unavailable-time recovery. Use the supplied vehicle
photo as the product evidence.

## 5. Kala / cultural visit

Create a public cultural-space visit planner. A person needs to choose a day and
ticket time while understanding programme, access, arrival, and change options.
Use the supplied courtyard photo as context. The product is the visit, not a
generic arts-brand homepage.
