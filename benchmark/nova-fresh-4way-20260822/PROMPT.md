# Seven-way fresh-generation protocol

Brief:

> Build a landing page for a creative studio called NOVA.

Each lane is a new standalone HTML artifact authored from the corresponding Git snapshot.
The seven pages use the same brief, same current model, same offline-safe delivery target,
and the same desktop/mobile verification steps. Prior benchmark HTML was not used as
implementation input.

`e6c1acd` receives one original local SVG hero asset because that snapshot adds an explicit
media-routing decision. Its provenance is recorded in `assets/MEDIA-PROVENANCE.md`; it has
no remote dependency or third-party source.
