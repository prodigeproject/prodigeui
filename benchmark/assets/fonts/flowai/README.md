# FlowAI benchmark font bundle

These fonts are bundled locally so the FlowAI benchmark keeps its intended typography without a CDN dependency.

| Local file | Upstream source | License copy |
| --- | --- | --- |
| `Recursive-VF.ttf` | `https://github.com/google/fonts/tree/main/ofl/recursive` | `OFL-Recursive.txt` |
| `Manrope-VF.ttf` | `https://github.com/google/fonts/tree/main/ofl/manrope` | `OFL-Manrope.txt` |
| `DMMono-Regular.ttf`, `DMMono-Medium.ttf` | `https://github.com/google/fonts/tree/main/ofl/dmmono` | `OFL-DMMono.txt` |

The binary files and adjacent license texts were downloaded from the official Google Fonts repository on 2026-07-14. They are benchmark-local assets and are not added to the ProdigeUI system asset registry.
