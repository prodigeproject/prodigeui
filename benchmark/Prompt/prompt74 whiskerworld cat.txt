## Prompt to Recreate WhiskerWorld — Premium Cat Lifestyle Landing Page

**Build a single-page "WhiskerWorld" premium cat lifestyle brand landing page using React, Tailwind CSS, and Lucide React icons. The page has a cinematic hero with looping video, product showcase cards, and smooth scroll-driven animations. Use Vite + TypeScript.**

---

### Fonts (Google Fonts)
- **Playfair Display** (weights: 400, 500, 700) — hero heading, section titles
- **Inter** (weights: 300, 400, 500, 600) — body/UI text

Load via `<link>` in `index.html`:
```
https://fonts.googleapis.com/css2?family=Playfair+Display:wght@400;500;700&family=Inter:wght@300;400;500;600&display=swap
```

Apply: `body { font-family: 'Inter', sans-serif; }` and `.font-display { font-family: 'Playfair Display', serif; }`

### Animations (CSS keyframes)

| Class | Effect | Duration | Easing |
|-------|--------|----------|--------|
| `.animate-fadeIn` | opacity 0→1 | 0.8s | ease-out |
| `.animate-slideUp` | translateY(30px)→0 + opacity 0→1 | 0.9s | cubic-bezier(0.16, 1, 0.3, 1) |
| `.animate-scaleIn` | scale(0.95)→1 + opacity 0→1 | 0.7s | cubic-bezier(0.16, 1, 0.3, 1) |

All with `animation-fill-mode: both`. Delay utility classes: `.delay-200` through `.delay-1000` in 200ms steps.

**IntersectionObserver:** elements with `.reveal` class start at `opacity-0 translate-y-6`, gain `.revealed` class (opacity-1 translate-y-0 transition duration-700) when 15% visible.

### Key Technical Details
- Smooth scroll: `html { scroll-behavior: smooth; }`
- Grain overlay: fixed, full-screen, pointer-events-none, z-50, opacity-[0.03], SVG noise texture
- All images have loading="lazy" except hero video
- Responsive: mobile-first, breakpoints at sm(640), md(768), lg(1024)
- Lucide icons used: Search, ShoppingBag, Heart, Share2, Play, ChevronDown, Menu, X, Instagram, Twitter
