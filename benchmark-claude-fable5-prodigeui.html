ProdigeUI Quality Bench • benchmark landing page

Satu brief, satu model, dua landing page.

Claude Fable 5 diberi brief identik dua kali: membuat landing page lengkap untuk AliranKas (SaaS arus kas UMKM). Run A tanpa sistem apa pun; Run B dengan seluruh kontrak ProdigeUI. Kedua halaman jadi ditampilkan utuh di bawah — scroll masing-masing, atau buka di tab penuh.

Run A — tanpa ProdigeUI Landing page refleks: gradien kategori, kartu setara, klaim tanpa bukti

GATE: FAIL • 3/100

Temuan audit utama

  • ✕Tidak ada bukti produk: 6 kartu fitur, 3 testimoni, dan 3 kartu harga semuanya generik — bisa ditempel ke SaaS mana pun.
  • ✕40+ nilai hex mentah, 5 gradien tanpa alasan, palet ungu-pink dipilih karena refleks kategori “AI”.
  • ✕Banyak pasangan teks gagal WCAG AA; CTA 32px; hue baru (teal) muncul hanya di CTA penutup; nav overflow 46px di 375px.

Run B — ProdigeUI penuh Profil operationalProduct: bukti operasional, satu sinyal, ritme berganti

GATE: PASS • 100/100

Temuan audit utama

  • ✓Artefak fokal: catatan operasional kas dengan noun domain (invoice, tenggat, piutang), risiko nyata, dan satu keputusan — berbagi viewport pertama dengan headline.
  • ✓Semua nilai visual dari token semantik; pricing memakai satu paket unggulan + alternatif ringkas, bukan tiga kartu setara.
  • ✓Kontras AA terverifikasi, target ≥ 44px, motion dari token kanonik, CTA penutup memakai ulang sinyal biru.
