# Provenance and Redistribution Matrix

| Material class | Origin | Known license | Redistribution status | Required action |
|---|---|---|---|---|
| ProdigeUI prose, JSON, schemas, recipes | Internal/adapted | No visible repository-wide grant | **Blocked / unknown** | Owner must choose and add a license before distribution |
| ProdigeUI illustrations | Declared original | Manifest says “ProdigeUI License,” but no license text exists | **Blocked / unknown** | Replace label with an actual grant or keep internal |
| Lucide-derived SVG icons | Lucide | ISC | Allowed subject to ISC notice | Preserve source/license metadata |
| Inter, JetBrains Mono, Geist | Official font projects; files not bundled | SIL OFL 1.1 | Obtain from official source | Bundle OFL text if fonts are later included |
| Research summaries | Conceptual generalizations from cited sources | Varies / often unrecorded | Internal reference only | Record upstream revision, canonical URL, and license before redistributing source material |
| Remote fallback image URLs | Third-party providers | Per-item provenance incomplete | **Blocked for production** | Record provider, author, asset URL, license, retrieval date |
| GSAP / ScrollTrigger examples | GreenSock ecosystem | Product-sensitive | **Restricted pending clearance** | Prefer Motion/native APIs; obtain product/legal approval before shipping |
| Lenis / Three.js / Motion references | Upstream projects | Verify at adoption time | Conditional | Pin version and retain upstream license/notice |

This matrix deliberately separates known licensed assets from unknown material. It does not
declare the corpus safe merely because a concept or URL is publicly accessible.
